# 7K RTA Draft

เว็บสำหรับ Ban/Pick ดราฟ RTA ของ Seven Knights Rebirth แบบออนไลน์
มีผู้ชม 1 คนเป็นคนเปิดและคุมห้อง ส่วนผู้เล่น 2 คนเข้าห้องผ่านลิงก์ลับของแต่ละฝั่ง
ไม่ต้องสมัครสมาชิก ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง ทุกอย่างอยู่ในไฟล์ `index.html` ไฟล์เดียว
link: https://dollyfish.github.io/7k-RTA-Banpick/

## วิธีใช้

### ผู้ชม (คนสร้างห้อง)
1. เปิดเว็บ แล้วกด **สร้างห้องออนไลน์ (ผู้ชม)**
2. กด **คัดลอกลิงก์** ของฝั่งน้ำเงินและฝั่งแดง แล้วส่งให้ผู้เล่นคนละลิงก์
3. ตั้งชื่อผู้เล่นทั้งสองฝั่ง แล้วรอให้สถานะขึ้น "เข้าห้องแล้ว" ทั้งคู่
4. กด **เริ่มดราฟ**
5. **เปิดหน้านี้ค้างไว้ตลอดการดราฟ** เพราะหน้าของผู้ชมคือตัวห้อง

ผู้ชมทำอะไรได้บ้าง:
- เห็นว่าผู้เล่นที่ถึงตากำลังจิ้มฮีโร่ตัวไหนอยู่ (กรอบประสีทอง)
- **เริ่มใหม่:** ล้างผลดราฟทั้งหมดแล้วกลับไปรอเริ่ม
- **สร้างลิงก์ใหม่:** นำผู้เล่นฝั่งนั้นออก และลิงก์เก่าจะใช้ไม่ได้อีก
- **ปิดห้อง:** ปิดห้องและให้ผู้เล่นทุกคนออก
- ถ้าเผลอปิดหน้าไป ให้เปิดเว็บใหม่ในเบราว์เซอร์เดิม แล้วกด **กลับเข้าห้องเดิม**

### ผู้เล่น
- กดลิงก์ที่ได้รับ ระบบจะเข้าห้องให้อัตโนมัติ
- เมื่อถึงตา ให้เลือกฮีโร่ให้ครบจำนวนแล้วกด **ยืนยัน**
- ถ้าเน็ตหลุดหรือรีเฟรชหน้า ระบบจะต่อกลับให้เอง แต่ต้องเป็นเบราว์เซอร์และแท็บเดิม

### กติกาในระบบ
- ลำดับดราฟมี 8 เฟส รวม 14 ตา: Ban 1 → Pick 1 → Pick 2 → Pick 3 → Ban 2 → Pick 4 → Pick 5 → Pick 6 ได้ทีมละ 5 ตัว และแบนทีมละ 2 ตัว
- ตาละ 60 วินาที ถ้าหมดเวลา ระบบจะล็อกตัวที่เลือกค้างไว้ แล้วสุ่มเติมช่องที่ยังว่าง
- ถ้ามีผู้เล่นหลุด **เวลาจะหยุด** จนกว่าจะกลับเข้าห้อง
- **ลิงก์ละ 1 คน:** คนอื่นที่กดลิงก์เดียวกันซ้ำจะเข้าไม่ได้
- ไม่มีช่องให้เข้าห้องด้วยรหัส ต้องเข้าจากลิงก์เท่านั้น
- ยังมีโหมด **เล่นเครื่องเดียว** สำหรับดราฟบนเครื่องเดียวโดยไม่ต้องสร้างห้อง
